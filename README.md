# Pulse

A HIIT interval timer that won't let you cheat the rest. Configurable work / rest / rounds,
Tabata-style presets, 10-second get-ready phase, audio countdown cues, color-coded phases
(green = work, red = rest), pause/resume, and total-time preview.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/pulse-timer/

Pure client-side HTML/CSS/JS. Beeps synthesized with the Web Audio API.
